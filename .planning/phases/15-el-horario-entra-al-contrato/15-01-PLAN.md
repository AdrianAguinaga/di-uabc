```python
class Bloque:
    """Una franja de clase del grupo en la semana: día, horas y ambiente.

    No es una `Sesion`: la sesión es un tramo de la actividad de una meta; el bloque es una
    franja del horario del grupo. Comparten el vocabulario de `AMBIENTES` y nada más (D-03).

    dia: int  # 0=lunes … 5=sábado
    inicio: str  # "HH:MM", como hora_entrega
```

```python
@dataclass
class Horario:
    """Vive en el grupo: si dos grupos tienen días distintos, las fechas divergen."""

    dias_presencial: list[int] = field(default_factory=list)  # 0=lunes … 5=sábado
    dia_entrega: int = 5  # sábado
    hora_entrega: str = "23:59"
    aula: str = ""
    bloques: list[Bloque] = field(default_factory=list)

    def __post_init__(self) -> None:
        # Llegan como dicts desde el YAML (`Horario(**g["horario"])`) o ya construidos
        # desde una prueba: los dos casos entran por aquí.
        self.bloques = [b if isinstance(b, Bloque) else Bloque(**b) for b in self.bloques]
        if self.bloques and self.dias_presencial:
            raise ErrorModelo(
                "Horario: declara bloques o dias_presencial, no ambos. Con bloques, "
                "dias_presencial se deriva de los presenciales — quita dias_presencial."
            )
        if self.bloques:
            self.dias_presencial = sorted(
                {b.dia for b in self.bloques if b.ambiente == "presencial"}
            )
```

Tres decisiones de forma que van con esto y que no hay que redescubrir:

1. **El derivado se escribe en el mismo campo `dias_presencial`**, no en una propiedad nueva. Así
   `generar.py:227`, `grafo.py:274` y `resolver_fechas` siguen leyendo `list[int]` sin cambiar de
   forma, que es lo que protege la huella de los cursos sin bloques.
2. **`dias_presencial: []` junto a `bloques` no es error**: una lista vacía no declara nada y el
   derivado gana. El conflicto de D-02 es entre dos verdades, y `[]` no es una verdad.
3. La conversión de dicts vive en `__post_init__` y no en `_construir_grupo`, para que
   `Horario(bloques=[{...}])` funcione igual desde el YAML y desde una prueba.
